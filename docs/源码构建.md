# 从源码构建译芽

## 环境

- macOS 13+，Apple Silicon 或 Intel。
- Xcode Command Line Tools，提供 clang、SDK、lipo、codesign 等；未安装时运行 `xcode-select --install` 并完成系统安装提示。
- Python 3.9+。普通构建和资料安装仅使用标准库；重新生成图标才需要 Pillow，现成图标已提供。

在源码根目录执行以下命令。下载的源码压缩包解压后，先进入 `fuyi-0.2.0` 文件夹。本机已有仓库目录可能沿用旧名称，目录名不代表源码版本；以 `VERSION`、Git提交和实际App构建号为准。

## 安装匹配的词典快照

数据库约 154 MiB，源码仓库中只保留来源、许可证和 SHA-256 校验清单。请从与源码对应的 Release 下载 `fuyi-reference-20261004.zip`：

```bash
python3 scripts/reference-data.py install "$HOME/Downloads/fuyi-reference-20261004.zip"
python3 scripts/reference-data.py check
```

安装器会核对完整文件清单、逐文件 SHA-256 和 SQLite 完整性，校验通过后才写入 `resources/learning/reference`。它不会访问用户的学习数据库。不要用其他版本资料包绕过校验。

## 构建、检查和本机安装

```bash
scripts/build-app.sh
scripts/run-checks.sh
scripts/install-app.sh
open "$HOME/Applications/译芽.app"
```

默认构建 arm64 + x86_64。只做本机快速构建时可以运行 `ARCHS=arm64 scripts/build-app.sh` 或 `ARCHS=x86_64 scripts/build-app.sh`。最低系统目标默认 13.0。

安装脚本会退出运行中的译芽、备份旧 App 并安装到 `~/Applications`。产物在 `dist/译芽.app` 时仍是组装中间产物，使用安装脚本完成本机签名。

测试会创建独立的临时数据并使用模拟 API 请求。测试输出位于 `.build/test-results/`，不会作为源码或用户资料发布。自动化测试不等于真实采集卡、多屏、全屏或新机器安装验收。

单独运行某组测试：

```bash
scripts/run-tests.sh
scripts/run-learning-tests.sh
scripts/run-learning-app-tests.sh ReferenceDictionaryTests
scripts/run-learning-app-tests.sh CollectionLayoutTests
```

## 更新离线资料（维护者）

`scripts/import-reference-data.py --download` 从上游下载资料，并在本机 `.build` 中缓存。重新生成后需重新检查来源许可、例句署名与等级匹配，再运行 `python3 scripts/reference-data.py create-lock` 登记新快照。提交新的来源及校验清单，并为该源码版本发布新的资料附件。

`create-lock` 会接受当前资料生成新的校验值，因此它属于维护流程，不是下载资料校验失败后的修复方法。

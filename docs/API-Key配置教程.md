# 译芽 · API Key 配置教程

译芽在本机识别画面，翻译和 AI 解析需要调用你配置的服务。API 调用费用由该服务商从你的账户收取；价格和账户要求以服务商官网为准。

## 使用 DeepSeek

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，按平台要求注册并开通 API 使用。
2. 在平台的 API Keys 页面创建 Key，复制后只保存在自己能访问的位置。不要发给作者或其他人。
3. 打开译芽的「翻译服务」页，点 **DeepSeek Flash**。
4. 在「API Key」框粘贴 Key，或点「从剪贴板粘贴」。配置会自动保存，不需要找单独的保存按钮。
5. 确认 Base URL 为 `https://api.deepseek.com`，「模型名」和「实时模型」为 `deepseek-flash`。学习模型可留空，复用模型名。
6. 点 **测试翻译**。看到成功结果后，回到「运行设置」选择窗口并开始翻译。

上述地址和模型名依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/) 核对于 2026-10-05。服务商可能更改可用模型；若模型名失效，请按官网更新。

「实时优先 / 准确优先」位于运行设置，调整本地识别策略；云端模型由翻译服务页的三个模型字段控制。需要尝试其他模型时，先点「测试翻译」确认兼容性。

## 使用其他服务

译芽使用 OpenAI 兼容的 **Chat Completions** 协议。选择「OpenAI 预设」或填写服务商提供的 Base URL、模型名和 Key；服务商给出的地址需支持 `/chat/completions`。仅提供 Responses 或其他协议的服务不能直接通用。

实时翻译使用「实时模型」，整屏快照使用「模型名」，语法解析使用「学习模型」（留空复用模型名）。切换服务后请同时核对所有模型字段，避免把其他服务的模型名带过去。

## Key 和文字会去哪里

- API Key 随认证请求发送给你配置的服务；OCR 文字、问题和相关上下文也会发送给它。
- 识别画面在本机处理，当前翻译请求发送文字。
- Key 保存在 macOS 钥匙串。旧版明文偏好设置会在迁移成功后删除 Key 字段；如果钥匙串不可用，原设置会保留并在界面提示。升级前的备份可能仍有旧 Key。
- 如果怀疑 Key 泄露，到服务商平台撤销并新建。分享求助截图时隐藏 Key 和个人内容。

## 失败时先检查

| 提示 | 检查方法 |
| --- | --- |
| 认证失败 / 401 | 检查 Key 是否属于当前服务、是否多了空格，以及是否已被撤销 |
| 余额或配额不足 | 去服务商控制台查看账户余额与使用额度 |
| 模型不存在 / 无权限 | 按服务商官网核对三个模型字段以及账户权限 |
| 请求太频繁 / 429 | 暂停后重试，适当降低识别频率 |
| 服务繁忙 / 超时 | 查看服务商状态与本机网络，稍后重试 |
| 格式错误 / 400 | 核对接口协议、地址与模型；反馈时只提供状态码和复现步骤，不贴服务响应正文 |

也可以先只点「测试翻译」：如果它失败，先解决接口配置；如果测试成功但画面没有译文，再检查屏幕录制权限、所选窗口和识别区域。

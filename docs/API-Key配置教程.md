# 译芽 · API Key 配置教程

译芽在本机识别画面，翻译和 AI 解析需要调用你配置的服务。API 调用费用由该服务商从你的账户收取；价格和账户要求以服务商官网为准。

## 使用 DeepSeek

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，按平台要求注册并开通 API 使用。
2. 在平台的 API Keys 页面创建 Key，复制后只保存在自己能访问的位置。不要发给作者或其他人。
3. 打开译芽的「翻译服务」页，点 **DeepSeek Flash**。
4. 在「API Key」框粘贴 Key，或点「从剪贴板粘贴」。配置会自动保存，不需要找单独的保存按钮。
5. 确认 Base URL 为 `https://api.deepseek.com`，「翻译模型」为 `deepseek-flash`。实时字幕和翻译当前界面都使用这个模型。
6. 点带播放图标的 **测试翻译**。按钮旁以绿色勾或红色感叹号显示成功或失败，测试中显示时钟。下方标出「测试模型 · 与实时字幕一致」，浅色结果框显示原文、译文或完整错误原因，可选择复制。看到成功结果后，回到「运行设置」选择窗口并开始翻译。

上述地址和模型名依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/) 核对于 2026-10-05。服务商可能更改可用模型；若模型名失效，请按官网更新。

翻译服务页只需填写一个「翻译模型」，测试翻译和实际翻译使用同一个模型。需要尝试其他模型时，修改后再点「测试翻译」确认兼容性。

## 使用其他服务

译芽使用 OpenAI 兼容的 **Chat Completions** 协议。选择「OpenAI 预设」或填写服务商提供的 Base URL、模型名和 Key；服务商给出的地址需支持 `/chat/completions`。仅提供 Responses 或其他协议的服务不能直接通用。

实时字幕、翻译当前界面和测试翻译统一使用「翻译模型」。语法解析默认复用它；需要单独指定时，展开「高级选项」，填写「学习模型（可选）」。切换服务后请核对翻译模型；如果设置了学习模型，也要检查它是否适用于新服务。

从旧配置迁移时优先保留原「模型名」；只有原模型名为空时，才使用原「实时模型」。保存后只保留一个翻译模型配置。这项调整不改变 API Key 文件；包含 2026-10-11 跨版本保留改动的应用包在重建、重装、重开及跨版本更新后均自动读取已有 Key。

## Key 和文字会去哪里

- API Key 随认证请求发送给你配置的服务；OCR 文字、问题和相关上下文也会发送给它。
- 识别画面在本机处理，当前翻译请求发送文字。
- Key 保存在当前用户的 `~/Library/Application Support/com.nanami.fuyi/credentials/api-key.json`，目录权限为 0700、文件权限为 0600。包含 2026-10-11 跨版本保留改动的应用包在重开、重装、build 递增和应用版本升级后均自动读取原 Key；已发布 0.2.1 build 17 仍按旧规则匹配版本，公开附件尚未更新。不会访问钥匙串或要求电脑密码，也不会随源码或应用包分发。升级前的备份可能仍有旧 Key。完整规则见 [API Key 本机保存约定](api-key-storage.md)。
- 如果怀疑 Key 泄露，到服务商平台撤销并新建。分享求助截图时隐藏 Key 和个人内容。

## 失败时先检查

实际翻译失败时，译芽会在现有错误位置提示前往「翻译服务」点击「测试翻译」，重新检查当前模型服务，同时保留原错误原因。升级合并模型后也按此流程处理，不额外弹出模型选择界面；模型或 Key 不会因此被自动更改。

| 提示 | 检查方法 |
| --- | --- |
| 认证失败 / 401 | 检查 Key 是否属于当前服务、是否多了空格，以及是否已被撤销 |
| 余额或配额不足 | 去服务商控制台查看账户余额与使用额度 |
| 模型不存在 / 无权限 | 按服务商官网核对「翻译模型」以及账户权限；语法解析失败时再检查高级选项中的学习模型 |
| 请求太频繁 / 429 | 暂停后重试，适当降低识别频率 |
| 服务繁忙 / 超时 | 查看服务商状态与本机网络，稍后重试 |
| 格式错误 / 400 | 核对接口协议、地址与模型；反馈时只提供状态码和复现步骤，不贴服务响应正文 |

也可以先只点「测试翻译」：如果它失败，先解决接口配置；如果测试成功但画面没有译文，再检查屏幕录制权限、所选窗口和识别区域。

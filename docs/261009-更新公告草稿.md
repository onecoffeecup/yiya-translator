# 译芽更新公告草稿

这次更新主要优化了游戏中的实时翻译、画面预览和界面贴译，也把翻译服务设置整理得更直观。

## 实时翻译更及时地跟随画面

- 对白识别的检查周期缩短，减少固定等待。
- 翻译还没返回时，会继续识别新画面。确认新的对白或页面后，旧请求返回的译文不会再覆盖新内容。
- 修复暂停后重启、快速切换对白和返回上一句时的部分状态问题；相同文字正在翻译时不会反复提交请求。
- 修正第三方接口上部分 DeepSeek 模型的推理参数判断。

实际译文返回速度仍取决于翻译服务和网络。

## 画面预览独立刷新

- App 内的画面预览不再跟着翻译请求一起等待。
- 采集卡预览目标提升至 30 fps，实际帧率随设备和系统变化。
- 窗口最小化、完全遮挡或切到其他桌面时，会暂停预览处理，重新可见后恢复。
- 切换窗口或输入源后，旧画面不会回填；减少同一采集帧被重复识别的情况。

## 修复识别和贴译问题

- 修复英文对白及界面文字带句号或省略号时，被误当作无效内容过滤的问题。
- 优化姓名、多行短对白和下半屏选择列表的判别，减少对白与选项互相误判。
- 修复部分靠右的正文贴译跑进左侧菜单，以及长卡更新后正文宽度变化的问题。
- 普通贴译卡片移除“中文译文”标题，只保留译文；展开阅读仍保留标题和原生选择、滚动操作。
- 优化旧位置回调和新布局的衔接，减少不必要的重新布局；位置变化时使用最新已确认的原文位置。

## 翻译服务设置更清楚

- “模型名”和“实时模型”合并为一个“翻译模型”。实时字幕、翻译当前界面和测试翻译使用同一个模型。
- “学习模型”收进“高级选项”，留空时复用翻译模型，也可以单独指定。
- 测试状态和错误说明放回“翻译服务”页，与测试按钮一起显示；成功后可以直接看到测试原文和译文，不会覆盖游戏字幕。
- 补上播放、成功勾、失败提示、测试中时钟和模型图标，结果使用浅色圆角框，错误和译文都可以选择复制。
- 开始翻译、切换窗口或输入源时，服务测试仍会继续；修改配置后旧测试结果会清除。
- 修正长短文本请求的超时判断，避免菜单短请求被误判为长正文。

## 其他稳定性改进

- 新字幕不再继承上一段文字的整段选中高亮，选择和复制功能继续保留。
- 优化收藏与译文记录写入、词典异常提示和语法片段处理。
- 未安装圆体字体的电脑会直接使用本机回退字体，避免等待系统下载。
- 移除旧识别设置的残留影响，统一识别策略；补充失败恢复、快速切换和界面布局的自动回归检查。
- 普通诊断优先保留最近的接口耗时与错误信息；默认发行构建禁用画面布局采样，普通反馈包仍不含密钥、截图或台词。

## 更新后的配置提醒

如果之前“模型名”和“实时模型”填得不一样，更新后会优先沿用原“模型名”。建议打开“翻译服务”页核对一次，再点击“测试翻译”。

本次待发布包已加入跨版本保留 API Key：重装、更新 build 或升级应用版本号都会自动读取原 Key，无需因更新重新填写。正式公告前须核对公开包已包含此改动；已发布的 0.2.1 build 17 仍采用旧规则。

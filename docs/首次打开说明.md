# 译芽 · 首次打开说明

适用版本：0.2.0 早期测试版。需要 macOS 13+、联网以及自备翻译服务 API Key。

## 解压与安装

1. 从项目 Release 下载 `yiya-0.2.0.zip`。可用同页的 `.sha256` 文件核对下载完整性。
2. 解压得到「译芽-0.2.0」文件夹，其中有 App 和说明文档。此包已包含离线词典。
3. 把「译芽.app」拖进「应用程序」（`/Applications` 或你自己的 `~/Applications`），再尝试双击打开。

## 系统阻止打开时

当前发布包采用 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。系统不能据此确认开发者身份或排除恶意软件，不能把所有警告都当作无害提示。

如果提示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」，且你确认文件来自可信的项目发布者并未被篡改，可以按 [Apple 的打开说明](https://support.apple.com/zh-cn/102445) 操作：

1. 先双击 App，看到提示后关闭提示框。
2. 打开「系统设置 → 隐私与安全性」，找到「安全性」下的「仍要打开」。
3. 确认要打开该 App，并按系统提示输入密码或使用 Touch ID。

不同系统的按钮文字可能不同；有些版本不支持通过 Control 点按直接放行。不需要关闭整个系统的安全检查。

如果提示「将损坏你的电脑」或「App 已损坏」，先停止打开，重新下载并核对校验值，再向作者反馈原始提示。不要用“所有损坏提示都是模板”的解释忽略它。

## 授权屏幕录制

1. 在「系统设置 → 隐私与安全性 → 屏幕录制」找到译芽；部分版本名称为「屏幕与系统音频录制」。
2. 开启权限后完全退出译芽（`⌘Q`），再重新打开。也可以使用运行设置页的「重启 App」。
3. 把目标窗口放到前台；在「运行设置」选择窗口和识别区域。

如果仍然看不到画面，先确认目标窗口在屏幕上且权限已开启，再退出重开。将系统版本、芯片型号和提示信息反馈给作者。

## 翻译第一句

按同目录的「API-Key配置教程.txt」填写接口配置并点击「测试翻译」。测试成功后，在「运行设置」选择目标窗口，再点「开始翻译」。默认自动识别整画面，不要求先框选；菜单或公告可用「翻译当前界面」。

可选的「仅翻译手动框选区域」在成功框选后自动启用，实时翻译与当前界面只读框内；取消勾选恢复整画面。按 Esc 可退出框选。详见 [识别范围使用说明](识别范围.md)。

运行状态留在主窗口。切到其他应用时悬浮字幕可能隐藏；回到所选目标应用后恢复显示。

## 升级与本机数据

新版本解压后替换 App；新下载的文件可能再次触发系统检查。固定的 App 标识有助于保留权限，但不同系统或签名变化后仍可能要求重新授权。

学习记录保存在 `~/Library/Application Support/com.nanami.fuyi/learning.sqlite3`，与 App 分开。升级前可在退出 App 后备份该目录。API Key 当前保存在本机普通偏好设置中，不要分享这些设置文件或带 Key 的截图。

## 从下载到第一句

- [ ] 下载并校验 zip，解压后可见 App 和使用说明。
- [ ] 按系统提示成功打开，没有忽略“恶意软件 / 损坏”警告。
- [ ] 屏幕录制授权并重启后，能看到所选目标窗口的预览。
- [ ] 只按文档配置 API，点击「测试翻译」成功。
- [ ] 选择目标窗口，不预先框选，点击「开始翻译」，日文原句与中文译文出现。
- [ ] 不预先框选，点击「翻译当前界面」，能识别菜单或公告。

### 手动识别范围（2026-10-07 更新的 v0.2.0 附件）

- [ ] 成功框选后「仅翻译手动框选区域」自动开启；取消框选不会改变原设置。
- [ ] 框选层对准当前游戏画面，按 Esc 可退出；重新进入后仍可双击确认。
- [ ] 框内与框外都有文字时，实时翻译及「翻译当前界面」只翻译框内。
- [ ] 窗口截图贴译位置正确，不因裁剪出现偏移；框内小字放大不带入框外文字。
- [ ] 运行中调整范围，不出现旧范围请求的迟到结果；关闭手动模式恢复整画面。
- [ ] 重启后范围与开关恢复；旧版本设置升级默认保持整画面。
- [ ] 采集卡在实际视频画面内框选，边框与内容对应；无可用映射时提示定位/校准。
- [ ] 框选、滑块微调及区域预设都能更新识别范围。
- [ ] 切到其他应用、回到目标应用后，字幕显隐行为符合预期。
- [ ] 字幕外观中框选字幕与批量字幕的字色、字号、显示框宽高分别生效；两行译文的长卡不多留一行空白。

## 采集卡输入（如果使用）

- [ ] 运行设置里「识别输入源」能切到采集卡，「刷新设备」只列出外接采集设备。
- [ ] 首次点「开始翻译／重连采集卡」时自动弹出相机权限提示；允许后直接开始采集。
- [ ] 拒绝弹窗后译芽明确提示、不再重复弹窗，且没有改用其他摄像头；「打开相机权限设置」按钮此时才出现。
- [ ] 选择采集卡并「重连采集卡」后，状态行显示正在采集；字幕仍然显示在选定的 QuickTime／OBS 窗口上。
- [ ] QuickTime 有画面时，译芽的采集帧计数持续增长；若停在零帧，记录设备和诊断信息，并确认改用「窗口截图」能否继续。
- [ ] 同一句对白下反复显示／隐藏 QuickTime 录制条，OCR 不再因录制条缺字，不再重复请求翻译。
- [ ] 真实换句时字幕正常更新；界面类画面在已定位或校准的视频区域内贴译，无法定位时明确提示，不出现整体错位。
- [ ] QuickTime／OBS 的预览全程正常，字幕延迟可以接受。
- [ ] 拔掉采集卡后不再出现新译文；重新插上并「重连采集卡」后恢复。
- [ ] 切回「窗口截图」后，原来的窗口截图与贴译行为不变。

## OBS 显示（如果使用 OBS）

- [ ] 「要翻译的窗口」（采集卡模式下叫「游戏画面所在窗口」）选 OBS 的窗口后，字幕正常浮在 OBS 画面上。
- [ ] 打开 OBS 的**预览投影（窗口模式）**，字幕仍在投影窗之上，没有被盖住。
- [ ] 打开 **全屏预览／全屏投影**，字幕与贴译仍然可见并跟随投影窗口（不会自己消失或停在编辑器坐标上）。
- [ ] 退出全屏后字幕位置如常；切到别的应用仍会自动隐藏。

以下项目供实际验收填写，自动测试或历史回放通过不代填勾选。本轮安装与已验证范围见 [界面 OCR 稳定说明](inline-ocr-stability.md)；当前公开下载包未在本轮更新。

- [ ] 在背景持续运动的页面停留至少一分钟，已有字段译文不随小幅 OCR 坐标变化闪烁；真实换字、换页仍能更新。
- [ ] 「帰宅部」与「桜井琥一の弟。／スリルは彼の活力。」保持两块；备注本身的两行可以组成一个段落。

- [ ] 选择、展开、收起后行为正常；切换 OBS 主窗口与投影时跟随正确视频区域，不停留在旧窗口坐标。

## 0.2.1 玩家现场验收

本机 55 步完整回归及独立应用的手动升级已通过，真实玩家跨机器安装与升级仍需逐项记录。首次从 0.2.0 手动安装 0.2.1，之后在「译芽 → 检查更新…」使用 Sparkle。

- 更新入口可检查版本；后续有新版本时可下载、安装并重启；取消或更新失败后原应用与学习资料保留。
- 升级后填写一次 Key，同版本再次打开可自动读取，普通启动无钥匙串密码框。
- 语法简短结果、展开／收起解释、整句复核可用；失败仍可阅读已有结果。
- 点击复核后继续滚动，返回结果后留在当前阅读位置。
- 等待分词或词语提示期间切换原句／打开完整学习界面，不崩溃、不显示旧句提示。
- 姓名、社团和多行备注保持字段边界；同文日期不丢失，选择列表打开时不换位。

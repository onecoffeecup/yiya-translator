# 自动识别与手动框选范围

## 适用范围

本说明对应 2026-10-07 更新的 v0.2.0 附件。该标签曾有较早的下载包；请核对附件 SHA-256 或检查「运行设置」是否有「仅翻译手动框选区域」开关。

## 默认：自动识别整画面

选择输入源和游戏窗口后，直接点击「开始翻译」或「翻译当前界面」，不需要手动框选。默认保留整画面识别和文字自动定位；自动贴合文字开启时，符合条件的文字区域可放大再次识别。

## 可选：只翻译一块区域

适合只读对白、忽略任务栏/聊天文字，或自动识别选错内容的情况。

1. 运行设置选择正确的输入源及游戏画面所在窗口。
2. 点击「手动框选 OCR 区域」，拖出包含目标文字的矩形，松手确认；Esc取消。
3. 成功框选后自动开启「仅翻译手动框选区域」。实时翻译和「翻译当前界面」都只识别这块区域。
4. 可使用X、Y、宽、高滑块或区域预设调整范围。区域以画面的左上角为原点，使用相对比例保存，不必每换一句重新框选。
5. 取消勾选恢复整画面；原区域仍保存，下次可以重新启用。也可直接开启开关使用现有保存区域，但应先查看OCR框确认位置。

框内仍支持自动文字贴合与放大，第二遍不扩展到框外。窗口截图的贴译坐标还原到原画面，不以裁剪图作为整个窗口。切换范围会作废旧请求并重置识别状态；旧译文可能暂时留在显示中，直到新范围识别结果更新。

## 采集卡：先确认视频映射

识别输入来自采集帧，字幕跟随QuickTime/OBS等目标窗口。采集画面可能只占窗口一部分：请先连接设备，并让自动定位或手动画面校准建立视频映射；没有可靠映射时，框选会提示先定位/校准，不猜整窗。

- **视频画面校准**：告诉应用视频显示在屏幕哪里，解决坐标映射。
- **手动OCR范围**：告诉应用只识别视频中的哪一部分，限制识别内容。

若点击「手动框选 OCR 区域」时采集卡还没有画面，应用会在当前窗口提示连接设备，并提供「重连采集卡」按钮。若已有画面但尚未定位视频，应用会引导先框出视频在目标窗口中的位置，完成后继续进入 OCR 框选。取消任一步都不会改动原有 OCR 范围。

框选层只覆盖当前目标窗口中实际显示游戏画面的区域；按 Esc 可退出，未完成的框不会保存。若 OBS 在全屏投影和编辑器之间切换，点击框选时会重新核对实际显示目标。字幕外观页将单条悬浮译文（「框选字幕」）和多条贴译卡片（「批量字幕」）分别配置字号、字色与显示框宽高；这些外观设置不改变 OCR 识别范围。

二者不能互相替代。OCR边框按映射后的视频矩形显示；更换输入源、设备、窗口或游戏布局后应重新确认范围。采集卡模式的译文展示方式沿用现有策略，开启手动范围不会自动新增原位贴译。

## 限制与验证

手动范围不能恢复被不透明控件遮住的文字。截断文字或太小的框可能没有结果；请包含完整行。API调用仍需要网络、Key及额度，OCR与翻译可能出错。

本次已验证双架构构建、45组本机回归，以及裁剪尺寸、底左坐标还原、自动模式输出保持、无效区域不回退整画面的独立契约。自动回归不替代所有真实游戏、物理采集卡与多屏拖框测试。试用检查见[首次安装验收](首次安装验收.md)。

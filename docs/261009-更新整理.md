| 识别不再等待翻译回复 | 翻译请求在途时，继续识别新画面。确认新对白或新页面后取消旧任务，迟到的成功、错误和排队显示不能覆盖新内容。 | `3d4e405` |
| 在途同文不重复提交 | 画面文字不变时继续识别，但不会因旧请求耗时长或节流到期而不断重复请求。 | `3d4e405` |

| 全部并发请求统一取消与释放 | 停止或换目标时处理所有已登记的翻译任务，避免只取消最后一个批次；完成的任务及时释放。 | `21cb6c4`、`3d4e405` |
| 按实际请求模型判断 DeepSeek 推理参数 | 使用第三方兼容接口时，根据最终 URL 和模型决定关闭推理；避免给 DeepSeek 漏加参数，或给其他模型误加 DeepSeek 参数。 | `9553f92` |
| 移除旧识别设置的残留影响 | 删除识别间隔、快速 OCR、等待稳定及两种旧识别预设的生产设置与读写。统一使用准确 OCR 和现有稳定规则，旧存档不会悄悄改变策略。 | `6a623cf` |

## 公告措辞和升级提醒

- 可以写“优化实时识别与翻译衔接”“预览不再等待翻译回复”“修复英文句点文字被过滤”“统一翻译模型”“优化部分贴译位置和尺寸”。
- 采集卡 30 fps 是目标调度，不写成所有机器稳定 30 fps；0.5 秒是对白检查周期，不写成“0.5 秒必出译文”。
- 不写“所有卡顿、错位、漏字已彻底解决”，不把自动回归通过写成所有玩家实机通过。
- 原“模型名”和“实时模型”不一致时，更新后优先保留原“模型名”，提醒玩家到服务页核对并测试。
- 包含 2026-10-11 追加调整的包在重装、build 变化及跨应用版本升级后均保留并读取原 Key；已发布 0.2.1 build 17 仍执行旧版本匹配规则。公告须确认待发布包已包含该调整。
- 自动更新、语法快速分析、“展开解释”“深度复核”、大部分奶油棕主题及原采集卡输入在基线已经存在，不列为本轮新增。
- OCR 离线评估只是实验工具，没有接入正式应用；不把它、流式译文、繁体中文 OCR、ScreenCaptureKit 迁移、iPad／Windows 正式支持列入本轮玩家更新。
- 正式发公告前填入确定的版本号、下载／更新入口和发布日期，核对公开包确实包含这些提交，并完成待验收的服务页桌面检查。

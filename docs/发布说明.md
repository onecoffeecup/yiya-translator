# 译芽 0.2.0 · 重构与修复预发布

本轮将 OCR、几何、翻译、窗口策略拆分为独立模块；修复内存所有权、服务地址诊断和窗口列表遍历，补充模块与回归测试，整理公开源码打包。发布副本已通过双架构构建及 45 组本机验收（包括 UI 和剪贴板）；这不替代另一台 Mac 的首次安装验证。

普通使用者下载 `yiya-0.2.0.zip`（已内置词典）。源码构建另下载 `fuyi-source-0.2.0.zip` 与 `fuyi-reference-20261004.zip`；各附件提供 SHA-256 校验文件。

这是一个 macOS 实时字幕翻译与日语学习工具，最初用于通过采集卡和 QuickTime 玩日文游戏。

需要 macOS 13+、屏幕录制权限、联网和自己的翻译服务 API Key。此版本免费；接口费用由服务商从你的账户收取。

压缩包内包含：

- 译芽.app：Apple Silicon + Intel 双架构，已内置离线词典。
- 首次打开说明.txt：安装、系统提示与屏幕录制授权。
- API-Key配置教程.txt：服务配置及测试第一句。
- 首次安装验收.txt：试用检查和反馈方式。
- LICENSE.txt、THIRD_PARTY_NOTICES.md：源码及第三方资料许可。

先读首次打开说明，再配置 Key 和测试翻译。

此包采用 ad-hoc 签名，尚未经过正式 Developer ID 签名及 Apple 公证；不同机器首次安装仍待实际验收。全屏快捷键、多屏、中文输入法和长时间运行也需要更多试用反馈。API Key 当前保存在本机普通设置中。

离线词典的英文释义来自 JMdict，日文例句来自 Tatoeba，JLPT 等级来自 OpenJLPT 社区参考。AI 译文及语法解释可能有误，词典和参考等级也未经过完整人工审校。

反馈请附系统版本、芯片、复现步骤与报错文字，隐藏 API Key、设置文件和个人内容。

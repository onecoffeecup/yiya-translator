# 译芽 0.2.0 · 预发布附件更新（2026-10-07）

这次沿用 v0.2.0 标签并替换同名附件。若之前下载过 0.2.0，请重新下载，并用本次附件附带的 `.sha256` 文件核对；旧包与新包虽然同名，内容不同。

本次更新加入手动框选 OCR 范围：默认仍识别整画面，框选成功后实时翻译与「翻译当前界面」共同受范围限制，Esc 可取消框选。框选层对准当前游戏画面；采集卡输入会先定位或校准视频区域。字幕外观现在分别控制框选字幕和批量字幕的字色、字号及显示框宽高。两行译文的长卡会随正文收紧，不再空占第三行；设置页切换时也不会把主窗口挤窄。

稳定性与安全性方面，学习数据读取增加 SQLite 空值保护；远程翻译服务地址只接受 HTTPS，HTTP 仅允许本机回环地址。AI 追问的服务错误在界面上改为概括提示，OCR 原文仍作为学习资料传给配置的服务，不应被视作应用指令。API Key 改存 macOS 钥匙串，旧设置首次成功迁移后清除明文 Key；诊断日志不再写入 OCR 原文，启用诊断时的日志和截图也写入当前用户的私有临时目录。

普通使用者下载 `yiya-0.2.0.zip`（已内置词典）。源码构建另下载 `fuyi-source-0.2.0.zip` 与 `fuyi-reference-20261004.zip`；每个附件都有同名 `.sha256` 校验文件。应用适用于 macOS 13+，需要自己的翻译服务 API Key；窗口截图模式需要屏幕录制权限，采集卡输入需要相机权限。此版本免费，接口费用由服务商向使用者收取。

一次现场试用中，QuickTime 已显示实时游戏画面，但译芽采集卡输入显示「采集中」而未收到新帧；原因尚未确认。遇到此情况可在「运行设置」改用「窗口截图」，并通过「诊断与反馈」导出状态供排查。采集卡模式不做原位贴译，界面译文显示在字幕窗。

此包采用 ad-hoc 签名，尚未经过 Developer ID 签名及 Apple 公证。另一台 Mac 的首次安装、Intel 实机、全屏与多屏、采集卡长时间运行仍需试用验证。旧版设置备份可能仍含 API Key；若曾分享备份，请到服务商撤销并重建 Key。AI 译文、语法解释、词典和参考等级可能有误。

反馈请附系统版本、芯片、复现步骤和诊断状态，并隐藏 API Key、设置文件及个人内容。

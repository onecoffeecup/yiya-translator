## 重现检查

在安装好匹配词典的源码目录中运行：

```bash
scripts/build-app.sh
scripts/run-checks.sh
scripts/release-app.sh
python3 scripts/reference-data.py pack
python3 scripts/package-source.py
```

本机完整构建 / 回归日志与界面检查截图保存在 `.build/release-validation/`，该目录不随公开源码发布。附件位于 `dist/release/`，各自附带 SHA-256 文件。后续源码或资料更新后需重新生成附件并检查。
